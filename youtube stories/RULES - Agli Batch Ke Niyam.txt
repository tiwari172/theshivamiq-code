1) FORMAT
- YouTube LONG VIDEO (16:9) primary. Shorts/Reels (9:16) usi se bante hain, alag story nahi.
- Ek batch = 10 case: 5 MEDIUM + 3 HARD + 2 VERY HARD, aasaan se mushkil order mein.
- Case ID: Category + number. Batch 1 = A-001 se A-010. Agla = A-011... (ya nayi category B-001, user batayega).
- Har case 8-10 suspects.
- KILLER KA NUMBER: har case mein alag hona zaroori NAHI (repeat ho sakta hai). Bas ek hi number baar-baar na aaye:
  ek batch mein koi bhi number max 2-3 baar, aur pichhli batches milakar koi number 4-5 baar lagatar/zyada na ho
  (pehle reels mein killer/chor hamesha 3 number par tha – wo galti dobara nahi). Pehla, beech, aakhri – sab jagah aaye.
  Batch 1: 7,2,9,6,4,1,10,3,8,5 | Batch 2: 3,8,5,10,1,6,9,2,7,4 | Batch 3: 5,3,8,6,2,9,4,7,1,10
- Detective SHIVAM hi case solve karta hai (police/inspector nahi). Poses: S2_ series (Shivam Poses sheet).

2) PUZZLE NIYAM
- Sirf EK bayaan kisi saboot / pakke fact se takraata hai = killer. (Code wale pattern mein – jaise A-016 keypad – victim ka saboot hi naam batata hai.) Baaki sab bayaan saboot se mel khaate hain.
- Har masoom ke paas ek shak wali baat (motive / chaku / khoon jaisa) = red herring.
- Galat ishara: Shivam kisi masoom par shak dikhata hai (SPLIT_SCREEN / DIVE / MARKER sirf usi par).
- HARD = ek bahar ka fact (Google karna pade). VERY HARD = video ka saboot + bahar ka fact, 2-3 kadam.
- Fact hamesha pakka aur Google par milne wala. Answer Key mein "kyun" + search line.
- "BAHAR KA BAYAAN" style (user ko pasand, Batch 3 se): har suspect apne bayaan mein bahar ki duniya ka ek fact bolta hai
  (jagah, khel, itihaas, science, khaana, aasmaan...). Sab fact SACH, sirf kaatil ka GALAT. Fact 100% pakka hona chahiye –
  shak ho to mat lo. Medium = school GK, Hard = Google karna pade, Very Hard = saboot (date/jagah) + fact.
- Pattern VARIETY: ek batch mein ek pattern max 2 baar (40 patterns ki list: A jhooth pakdo, B chitra dekho,
  C number/logic, D code/shabd, E alag sawaal, F twist). Batch 1 mein "cheez band/kharab thi" 4 baar aa gaya – dobara nahi.
- Jawab screen par KABHI nahi. Jawab agle Sunday ki video ki shuruaat mein.

3) TITLE / HOOK / CAPTION
- Title = case ID + victim/jagah + suspense. Clue KABHI nahi (jaise "Fuse Bulb", "Peela Note" galat the).
- Hook = sirf suspense ("8 log, 8 bayaan... aur ek jhooth"). Hook mein suspect ki ginti short ke hisaab se badlo.
- HOOK MEIN ISHARA BHI NAHI (user, 2026-10-24): jhooth kis cheez ka hai (shehar/safar, samundar/lehar, khel, itihaas, taareekh, aasmaan, report...) hook ya screen text mein KABHI nahi. Sirf "kaatil kaun / ek jhooth / 99% fail" jaisa suspense. Batch 3 ke HOOKS (batch3_data.py) example hain.
- Shorts/Insta title + caption mein bhi clue nahi.

4) SABOOT
- Saboot KABHI bole nahi jaate: Saboot rows ka VO + Caption KHAALI, Sec = 1.5, sirf tasveer, sab ek jaise.
- Saboot ke time ek "jagah-set" line (saboot ka naam nahi): "Drawing room mein sab kuch waisa hi tha... Shivam ne har cheez par nazar daali."
- VO mein koi line clue ka sach/jhooth na bataye ("switch dabaya, kuch nahi hua", "battery khatam" jaisi lines NAHI). Clue sirf tasveer mein.
- Clue wale saboot par koi alag zoom / gola / peela NAHI.

5) VOICE
- Long video: ElevenLabs, har line ka alag tukda (narrator Rudra + har suspect ki apni awaaz), speed 1.05. Galti par sirf wahi tukda dobara.
- Reel: poori story EK BAAR mein (Rudra, eleven_v4, stability 0.45, speed 1.05 + purana tighten). Reel 55-60 sec.
- Reel VO mein NAHI: "bole/boli", motive line (sirf SUSPECT card par), "ab suniye sabke bayaan", jo photo mein dikhe
  ("haath laal"), galat-ishara line, saboot, "full video/link bio" line.
- EMOTION TAG KAM SE KAM (user ne kaha, 2026-10-24): sirf hook par [whispers]. Suspect ke bayaan par koi tag nahi (killer alag na lage). Jahan sach mein zaroori ho wahi tag.
- Reel end: 3 sec chup -> PAKAD_LIYA_HI + CTA_HI + SIGNATURE_HI (purani files, dobara nahi banti).
- Soch ke 3 sec chup (Shivam SOCH + tick_fast + PAUSE_HINT).

6) MOTION
- MOTION PLAN (16:9) + SHORTS MOTION PLAN (9:16): har Script line ko 2.5-3.5 sec ke beats mein (Beat = line no. + .1/.2/.3).
- MOTION column mein sirf MOTION CODES sheet ke code ('+' jodo, '->' ek ke baad ek). Naya effect: "NEW: <description>".
- Har case ka hook (SLAM_TITLE / TYPE_HOOK / SPLIT_FLAP+GLITCH) aur Shivam entry (SLIDE_R / SILHOUETTE_REVEAL / DOOR_LIGHT) baari-baari alag.
- Saboot = EVIDENCE_TRAY montage (sab same). Suspect = INTERROGATION + SUSPECT_CARD -> STATEMENT_SLIP -> SLIP_FLIP (sab same).
- HARD/VERY HARD title card par WARNING_STRIP. CASE_HUD poore case mein.
- Screen text max 3-4 shabd, Roman. SFX sirf line ke pehle beat par. Music: normal / DUCK / OFF (OFF sirf soch + pakad liya).
- Captions word-level, bolta shabd peela #FFE600. Style: dark case-file desk, film grain + vignette.
- (Laptop par: py yt_motion_plan.py "<Excel>" Script sheet se MOTION PLAN bana deta hai.)

7) SHORTS
- Har batch se 3 short: 2 MEDIUM + 1 HARD (Very Hard ka short nahi). Har short mein 5 suspect, killer + galat-ishara wala hamesha.
- Short ka apna hook. Reel max 90 sec. Jawab short mein KABHI nahi. Short ke comments par points nahi.

8) COVER
- Har case ka 9:16 cover: dark Shivam S2_17 close-up, chashme mein laal '?', kaala background, upar 'CASE A-00n' + level,
  beech case ka title, neeche KILLER KAUN?. Shivam ka glow = level ka rang (Medium hara, Hard naranji, Very Hard laal).
- YouTube thumbnail: "99% LOG FAIL!" + "10 KAATIL PAKDO", case ka naam/clue kabhi nahi.

9) PINNED / COMMENTS
- Comment format: "A-001 Naam". Long video pinned = format + points rule (like/subscribe se points nahi).
- Post karte hi (short/reel): "Kaatil kaun? Jawab agle Sunday. POINTS sirf full video par".
- Jawab ke baad (short/reel): jawab + 1 line kyun + "Jisne sahi pakda tha, is comment ko LIKE karo!".

10) FOLDERS (Claude Code banata hai)
youtube stories\Batch N\ : Excel + "00 Intro + Outro"\ + har case "A-00n <Title>"\ (script, VO, logic, motion csv, images, cover)
 + "YouTube Reels Story"\R1..R3 (shorts).

11) PURANI IMAGES PEHLE (kam se kam nayi image)
   -> Pehle "CHARACTER BANK - Purani Images.txt" padho (har image ka look likha hai). Victim ko sirf leti/jhuki image, suspect ko khadi image. Ek batch mein ek image max 2 baar.
- User ke paas 100-200 character + props images hain (G_ generic, C_ purani stories, P_ props). Har batch mein pehle inhi se match karo.
- Data file mein REUSE dict (batch3_data.py dekho): suspect -> purani asset, victim -> purani, saboot -> purana P_.
- G_ naam wale (Bhola, Ramu, Shanti, Kamla, Bahadur, Hariya, Sharma Aunty...) use karo to suspect ka NAAM bhi wahi rakho.
- Clue wali image (date/text wali) aur Background (16:9) aksar nayi banti hai. Image Prompts sheet mein HARA = purani image.
- Asset list ka source: cases\*.csv (pehli column). Laptop ke assets\ mein aur bhi ho sakti hain – user se contact sheet maango.

12) SAFE CONTENT
- Victim image mein khoon/ghav nahi. CRIME_TAPE theek, khoon ki boondein nahi. Points sirf sahi jawab par (YouTube niyam).

13) REEL SCRIPT CHECKLIST (user, 2026-10-24) – har batch ke baad: python _tools\check_batch.py <data module>  ("SAB THEEK" aana chahiye)
- Kaatil ki line baaki jitni lambi (10-15 shabd), same banawat/tone. "!", "kya nazara tha", "maza aa gaya" jaisi extra baat kisi ko nahi.
  Time ek line mein ho to sab lines mein ho.
- Har masoom ki line MAUT KE TIME + JAGAH ke saath padho – us waqt ye kaam sach mein ho sakta hai? (raat ko dhoop/safari/retreat nahi,
  monument ka band din, shop/lighting ka time). Shak sirf MOTIVE se (card par), line ke jhooth se nahi. Sirf EK bayaan galat.
- Naam + shehar title / card / VO / caption / image / Answer Key mein same. G_ image ho to data mein hi wahi naam likho (REUSE rename mat karo).
- Tag: sirf hook [whispers] + maut wali line [serious]. "Pakad liya" purani file, uspar tag nahi.
- "bole/boli" kahin nahi (narration mein bhi) – "sabne kaha".
- Kaatil ka card number ek batch mein max 2 baar, 1-5 sab aayein. Kaatil ko bhi kabhi motive do (motive-less = kaatil, ye pattern na bane).
- Ek pattern max 2-3 baar: date+fact, time ka fact, time ka hisaab, do logon ka takraav, cheez thi hi nahi, tasveer mein galti, code, record.
- GK fact 100% pakka + Answer Key mein search line. Ek se zyada matlab wale shabd se bacho ("sher" -> "babbar sher").
- Code/saboot wale case: jagah/setup line mein clue wali cheez ka naam nahi ("ek ishara chhoda tha" theek hai).
